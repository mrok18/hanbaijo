# FXレートデータ利用許諾 — 依頼文と確認手順

## ユーザーにお願いする作業

候補のFX会社またはASP担当者へ、下記の文面を送付する。
1社から必要範囲の書面回答が得られれば、その会社を最初のFX実測対象として実装できる。

優先順:

1. A8.netのFX案件担当者・広告主への問い合わせ
2. OANDA証券（正式APIの利用条件と公開サイトへの掲載可否）
3. 松井証券FX、外為どっとコム、LIGHT FX（公開レート画面の二次利用可否）

回答メール、許諾条件、利用規約の該当箇所を受け取ったら、このプロジェクトへ共有する。
APIキーやパスワードは共有せず、発行された場合は後でVercelの環境変数へ直接設定する。

## そのまま使える問い合わせ文

件名: FXレートデータの取得・統計化・掲載可否について

```text
ご担当者様

金融商品の取引コストを比較する情報サイト「金融コストウォッチ」
（https://hanbaijo.com/）を運営しております。

貴社が公式に提供するFXレートについて、以下の利用を検討しています。

・取得元: 貴社の正式APIまたは公式レートページ
・取得頻度: 30分ごと
・取得項目: 通貨ペア、Bid、Ask、スプレッド、取得時刻
・保存: 時系列データとして継続保存
・加工: 中央値、95パーセンタイル、時間帯別集計等の統計値を算出
・掲載: 最新値、集計値、推移グラフを出典・取得時刻付きで一般公開
・利用目的: 広告・アフィリエイトを含む商用情報サイトでの比較情報提供

元データそのものをダウンロード可能な形で再配布する予定はありません。

上記について、次の可否と条件をご教示いただけますでしょうか。

1. 自動取得
2. 取得データの継続保存
3. 統計化・円換算等の加工
4. 最新値・集計値・グラフの第三者向け掲載
5. 広告・アフィリエイトを含む商用利用
6. 必要な出典表記、表示遅延、免責文、更新頻度その他の条件
7. 専用契約、口座、API利用申請等の要否

可能な範囲と不可となる範囲を、書面またはメールでご回答いただけますと幸いです。
どうぞよろしくお願いいたします。
```

## 採用判定

次の全項目が明確に許可されるまで、自動収集は有効化しない。

- 自動取得
- 継続保存
- 統計加工
- 公開サイトへの掲載
- 商用・広告利用
- 指定された表示条件をサイト上で実装できること

「APIを利用できる」「公開ページで見られる」だけでは、保存・加工・再掲載の許可とは判断しない。

## 回答後にCodexが行う作業

1. 回答内容をソース台帳へ記録
2. 許可範囲に合わせて取得アダプターを実装
3. APIキーが必要な場合の安全な環境変数設定手順を提示
4. 欠測・レート制限・出典表記を含む検証
5. 作業ブランチで30分計測を試験
6. 公開前レビュー後に本番計測を有効化
