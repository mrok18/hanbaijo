## ユーザーにお願いする作業

候補のFX会社またはASP担当者へ、下記の文面を送付する。
1社から必要範囲の書面回答が得られれば、その会社を最初のFX実測対象として実装できる。

送付順:

1. A8.netのPC版メディア管理画面で、候補会社が「参加中プログラム」にあるか確認する。
2. 参加中なら `プログラム管理` → `参加中プログラム` → `プログラム詳細` → `広告主お問い合わせ` から送る。
3. 未提携またはA8.netに案件がない候補は、下記の各社正式窓口へ送る。

2026-09-07に提携申請が完了した。最新画面では、FXTF、シストレセレクト365、DMM CFDほか計7件が `提携完了`、主要FX各社を含む19件が `審査中`。提携完了した3つの金融商品案件から広告主問い合わせを開始できる。

送付先:

- A8.netの広告主問い合わせ手順: https://support.a8.net/a8/as/faq/2008/03/post_134.html
- A8.netサービス問い合わせ（未提携時）: https://support.a8.net/as/contact/
- 松井証券（口座未保有者向け商品・サービス問い合わせ）: https://matsui.webcas.net/form/pub/general/kouzakaisetsu
- 外為どっとコム: https://www.gaitame.com/inquiry/
- LIGHT FX: https://lightfx.jp/support/form/
- OANDA証券: https://www.oanda.jp/inquiry （カテゴリ「APIについて」）
- サクソバンク証券: https://www.home.saxo/ja-jp/platforms/api （ページ下部の「お問い合わせ」）

OANDA証券の個人口座向けREST APIは、Gold会員（前月50万米ドル相当以上の取引）、プロコース、NYサーバー口座残高25万円以上を継続して満たす必要がある。このため現時点では第一候補にしない。法人向け為替データAPIは `fxdata@oanda.com` が窓口だが、年額4,850米ドルからであり、必要性と予算が合う場合だけ検討する。

サクソバンク証券のOpenAPIは個人口座で指定初回預託額なし、API手数料なしだが、無料利用は私的使用目的に限られる。商用の保存・統計化・再掲載について個別許可または契約が可能かを問い合わせる。

FXTFはA8.net上で提携完了済み。公式サイトポリシーでは、許諾なしの翻案・公衆送信等を認めていないため、A8.netの広告主問い合わせから書面許諾を確認する。DMM CFDとシストレセレクト365も同様に、提携成立とデータ利用許諾を分けて確認する。

回答メール、許諾条件、利用規約の該当箇所を受け取ったら、このプロジェクトへ共有する。
APIキーやパスワードは共有せず、発行された場合は後でVercelの環境変数へ直接設定する。

## 採用判定

次の全項目が明確に許可されるまで、自動収集は有効化しない。

- 自動取得
- 継続保存
- 統計加工
- 公開サイトへの掲載
- 商用・広告利用
- 指定された表示条件をサイト上で実装できること

「APIを利用できる」「公開ページで見られる」だけでは、保存・加工・再掲載の許可とは判断しない。

## 回答後にCodexが行う作業

1. 回答内容をソース台帳へ記録
2. 許可範囲に合わせて取得アダプターを実装
3. APIキーが必要な場合の安全な環境変数設定手順を提示
4. 欠測・レート制限・出典表記を含む検証
5. 作業ブランチで30分計測を試験
6. 公開前レビュー後に本番計測を有効化
