## 提携申請の順序

1. 提携申請は完了済み。
2. 提携完了したFXTF、シストレセレクト365、DMM CFDの `広告主お問い合わせ` からデータ利用許諾文を送る。
3. 審査中案件は、承認された時点で同じ許諾確認を行う。正式OpenAPIがあるサクソバンク証券、既に利用条件を調査済みの松井証券・LIGHT FXを優先する。
4. APIや再掲載許諾が得られなくても、広告リンクは「公式公表条件の編集比較」「取引コスト計算機」「選び方記事」で使用する。
5. Bランクと周辺案件は、対応する記事・比較ページが完成してから申請する。

## 現在送れる問い合わせ

1. FXTF: FXレートの自動取得・保存・統計加工・商用掲載の許諾可否
2. DMM CFD: 指数・商品CFDレートの同条件での許諾可否
3. シストレセレクト365: 提示レート、ストラテジー成績等の取得・統計掲載の許諾可否

FXTFのサイトポリシーでは、許諾なしの翻案・公衆送信等を認めていない。提携完了はデータ再掲載許諾を意味しないため、広告リンク掲載とデータ取得許可を分けて管理する。

## サクソバンク証券APIの注意点

- 公式案内: https://www.home.saxo/ja-jp/platforms/api
- OpenAPIは、個人口座では指定初回預託額なし、API手数料なしと案内されている。
- 一方、無料利用は私的使用目的に限定される。
- 商用サイトでの自動取得、継続保存、統計加工、再掲載は、別途書面で許可されるまで有効化しない。
