## 提携申請の順序

1. まずAランクの9案件へ提携申請する。
2. 承認された広告主の `広告主お問い合わせ` から、FXデータ利用許諾文を送る。
3. データ許諾は、正式OpenAPIがあるサクソバンク証券、既に利用条件を調査済みの松井証券・LIGHT FXを先に確認する。
4. APIや再掲載許諾が得られなくても、広告リンクは「公式公表条件の編集比較」「取引コスト計算機」「選び方記事」で使用する。
5. Bランクと周辺案件は、対応する記事・比較ページが完成してから申請する。

## サクソバンク証券APIの注意点

- 公式案内: https://www.home.saxo/ja-jp/platforms/api
- OpenAPIは、個人口座では指定初回預託額なし、API手数料なしと案内されている。
- 一方、無料利用は私的使用目的に限定される。
- 商用サイトでの自動取得、継続保存、統計加工、再掲載は、別途書面で許可されるまで有効化しない。
