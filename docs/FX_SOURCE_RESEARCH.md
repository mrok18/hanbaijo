# FXデータ取得元の予備調査（2026-09-07）

## 結論

国内FX会社の公開レート画面を技術的に読めることと、レートを継続保存・加工・再掲載できることは別問題である。
現時点では自動取得を有効化せず、正式APIまたは提供会社の書面許諾で「取得」と「再掲載」の両方を確認できた提供元だけを採用する。

## 候補

### OANDA証券

- 公式案内: https://www.oanda.jp/platform/api
- REST APIで主要通貨ペアのリアルタイムレートを取得できる。
- 利用には口座、所定の会員ステータス・残高、API契約、パーソナルトークンが必要。
- APIを使えることだけでは公開サイトへの再配布許諾を意味しないため、時系列保存・集計値・画面掲載の可否を確認する。

### 松井証券FX

- 公開レート: https://www.matsui.co.jp/fx/market/rate/
- 公開ページは5秒ごとの更新と案内されている。
- FXアプリ利用規約では、サービス内容の蓄積・編集・加工・二次利用（第三者提供を含む）を禁止している。
- 公開Webページに同じ条件が直接適用されるかを含め、書面確認前はクローラーを作らない。

### 外為どっとコム

- 公開レート: https://www.gaitame.com/markets/rate/
- Bid、Ask、スプレッド、スワップ等を表示している。
- 取引約款では、付随情報を本人の取引目的に限り、第三者提供・営業利用・加工・再配信等を制限している。
- 公開ページの継続取得・再掲載を許す明示条件を確認できるまでは採用しない。

### LIGHT FX

- 公開レート: https://lightfx.jp/market/rate/
- FX口座のレートを表示する一方、実際の取引レートと異なる場合がある「参考レート」と明記している。
- 正式APIおよび再掲載許諾を確認できていないため、候補として保留する。

## 実装ゲート

各提供元について次の全項目がそろうまで `canCollect` と `canRepublish` を有効にしない。

1. 正式な取得方法が確認できる。
2. 自動取得の頻度が利用条件に適合する。
3. 元データの保存が許可される。
4. 集計値・時系列・最新値の第三者向け掲載が許可される。
5. 出典表示、遅延表示、免責その他の表示条件を実装できる。
6. APIキー等が必要な場合、サーバー側の秘密情報として管理できる。

## 次の実務

- ASP担当者または各社窓口へ「30分ごとの取得、統計化、出典付き公開」の可否を確認する。
- 許可が得られた提供元からUSD/JPY、EUR/JPY、GBP/JPYを開始する。
- 初期集計は中央値、95パーセンタイル、広告表示スプレッドの達成率、早朝・重要指標前後の拡大率とする。
