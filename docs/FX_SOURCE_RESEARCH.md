# FXデータ取得元の予備調査（2026-09-07）

## 結論

国内FX会社の公開レート画面を技術的に読めることと、レートを継続保存・加工・再掲載できることは別問題である。
現時点では自動取得を有効化せず、正式APIまたは提供会社の書面許諾で「取得」と「再掲載」の両方を確認できた提供元だけを採用する。

## 候補

### OANDA証券

- 公式案内: https://help.oanda.jp/oanda/faq/show/720?site_domain=default
- REST APIで主要通貨ペアのリアルタイムレートを取得できる。
- 利用には次の条件をすべて継続して満たす必要がある。
  - Gold会員（前月の取引量が50万米ドル相当以上）
  - プロコース
  - NYサーバーの口座残高25万円以上
  - API利用規約への同意とパーソナルトークン
- APIを使えることだけでは公開サイトへの再配布許諾を意味しないため、時系列保存・集計値・画面掲載の可否を確認する。
- 条件維持の取引負担が大きいため、MVPの第一候補から外す。
- 法人向け為替データAPIもあるが、料金は年額4,850米ドルからで、個別FX会社の提示スプレッド比較を代替するものではない。

### 松井証券FX

- 公開レート: https://www.matsui.co.jp/fx/market/rate/
- 公開ページは5秒ごとの更新と案内されている。
- 公開APIは公式案内内で確認できなかった。
- FXアプリ利用規約では、サービス内容の蓄積・編集・加工・二次利用（第三者提供を含む）を禁止している。ただし、この規定が公開Webページにも同じ範囲で適用されるとは断定しない。
- 公開Webページに同じ条件が直接適用されるかを含め、書面確認前はクローラーを作らない。

### 外為どっとコム

- 公開レート: https://www.gaitame.com/markets/rate/
- Bid、Ask、スプレッド、スワップ等を表示している。
- 公開APIは公式案内内で確認できなかった。
- サイト利用条件では、掲載情報の無断転載・複製を認めていない。
- 公開ページの自動取得・継続保存・加工・再掲載を許す明示条件を確認できるまでは採用しない。

### LIGHT FX

- 公開レート: https://lightfx.jp/market/rate/
- FX口座のレートを表示する一方、実際の取引レートと異なる場合がある「参考レート」と明記している。
- 公開APIは公式案内内で確認できなかった。
- サイト利用条件では、掲載情報を許可なく転載・公開することを認めていない。
- 正式な取得方法および再掲載許諾を確認できていないため、候補として保留する。

## 送付先

提携中の広告主については、各社の一般サポートより先にA8.netの管理画面から送付する。

1. A8.net PC版メディア管理画面
   - `プログラム管理` → `参加中プログラム` → 対象案件の`プログラム詳細` → `広告主お問い合わせ`
   - A8.net公式手順: https://support.a8.net/a8/as/faq/2008/03/post_134.html
2. 未提携またはA8.netに対象案件がない場合
   - 松井証券: https://matsui.webcas.net/form/pub/general/kouzakaisetsu
   - 外為どっとコム: https://www.gaitame.com/inquiry/
   - LIGHT FX: https://lightfx.jp/support/form/
   - OANDA証券: https://www.oanda.jp/inquiry （カテゴリは「APIについて」）
3. OANDA法人向け為替データAPIを検討する場合
   - `fxdata@oanda.com`

A8.netの未提携プログラムについて広告主へ直接問い合わせられない場合は、A8.netサービス問い合わせフォーム https://support.a8.net/as/contact/ を使用する。

## 実装ゲート

各提供元について次の全項目がそろうまで `canCollect` と `canRepublish` を有効にしない。

1. 正式な取得方法が確認できる。
2. 自動取得の頻度が利用条件に適合する。
3. 元データの保存が許可される。
4. 集計値・時系列・最新値の第三者向け掲載が許可される。
5. 出典表示、遅延表示、免責その他の表示条件を実装できる。
6. APIキー等が必要な場合、サーバー側の秘密情報として管理できる。

## 次の実務

- A8.netで各候補が「参加中プログラム」か確認し、参加中なら広告主問い合わせから「30分ごとの取得、統計化、出典付き公開」の可否を確認する。
- 未提携の候補は各社の正式窓口へ同内容を送る。
- 許可が得られた提供元からUSD/JPY、EUR/JPY、GBP/JPYを開始する。
- 初期集計は中央値、95パーセンタイル、広告表示スプレッドの達成率、早朝・重要指標前後の拡大率とする。
